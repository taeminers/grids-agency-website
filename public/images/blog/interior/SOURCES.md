# Interior website comparison photography

The ONDAM / 온담 인테리어 website concepts are fictional examples, not client
projects or claims about a real interior business. Both versions reuse the same
photography to compare layout and information hierarchy. Any displayed package
prices, locations, experience statements, and project labels are fictional UI copy.
