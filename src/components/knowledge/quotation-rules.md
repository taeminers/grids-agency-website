# 6. 외부 비용

다음 비용은 기본적으로 GRIDS 개발 견적에 포함하지 않는다.

- 도메인
- 서버 / 호스팅
- 외부 API 사용료
- PG사 비용
- SMS / 알림톡 발송 비용
- 유료 라이브러리
- 유료 폰트
- 이미지 / 영상 구매
- 기타 외부 서비스 비용

필요한 경우 고객에게 별도로 안내한다.

---

# 7. 추가 개발

최초 합의된 범위를 벗어나는 요구사항은
추가 개발로 판단하고 별도 견적한다.

예:

- 새로운 페이지
- 새로운 기능
- 새로운 외부 서비스 연동
- 승인된 디자인의 대규모 변경
- 기존 비즈니스 로직 변경
- 프로젝트 진행 중 새롭게 추가된 요구사항

---

# 8. 견적 계산

기본적인 견적 산정 방식:

기본 제작비

- 추가 페이지
- 추가 기능
- 다국어
- 특수 디자인 / 인터랙션
- 기타 추가 작업
  = 내부 산정가

내부 산정가를 기준으로 프로젝트 규모,
난이도 및 영업 상황을 고려하여
최종 제안 금액을 조정할 수 있다.

# 10. VAT

모든 내부 견적 기준은 VAT 별도이다.

고객에게 최종 견적을 전달할 때는
공급가액과 VAT를 구분하여 표시한다.

예:

공급가액: 5,000,000원
VAT: 500,000원
총액: 5,500,000원

---

# 11. 중요 원칙

이 문서의 가격은 견적 산정을 위한 기준이며
모든 프로젝트에 기계적으로 적용하지 않는다.

프로젝트의 실제 범위와 난이도를 우선한다.

정보가 부족한 상태에서는 확정 견적을 제시하지 않는다.

가격을 임의로 추측하지 않는다.

명시되지 않은 기능은 유사 기능의 가격을 임의로 적용하지 않고
필요한 경우 별도 산정한다.

견적이 애매한 경우 낮은 가격을 임의로 제시하기보다
추가 정보를 확인한 후 견적한다.
